# Kubota Family Voyage 2026 秋 — 東京ディズニーシー家族旅行のしおり

2026/10/27（火）前泊〜10/28（水）東京ディズニーシーの、家族で見るためのしおりサイトです。

## 機能
- 出発・開園までのカウントダウン
- 「いま / つぎ」表示（日本時間で自動判定。`?now=2026-10-28T09:05` を付けると時刻をシミュレーション）
- DAY1 / DAY2 タイムライン（公式サイト等へのリンク付き）
- 乗換ナビ：保谷→舞浜の早め・遅めの電車、好きな時刻、いまから検索、到着時刻指定、帰りの終電（Yahoo!乗換案内）
- リゾートライン時刻表・運行情報リンク
- 朝イチの役割分担、ねらうアトラクション
- 前夜チェックリスト（端末に保存）
- リンク集（公式・ホテル・天気・電話）

## 構成
ビルド不要の静的サイト（HTML / CSS / ES Modules）。Vercel にそのままデプロイできます。

```
npm test   # ロジックのテスト（Node 20+）
```
